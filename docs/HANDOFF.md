3. 창에 `http://127.0.0.1:5173/`가 표시되면 위 링크를 엽니다. 이 창을 닫으면 미리보기가 종료됩니다.
4. 휴대폰 크기의 완성 화면은 같은 폴더의 `preview/launch-blank-mobile.png`, PC 전체 화면은 `preview/launch-blank-desktop.png`에 있습니다. 휴대폰 기기에서 PC의 127.0.0.1 주소로 접속할 수는 없습니다.

## 관리자 체험
1. 홈 맨 아래 ‘운영자’를 누르거나 [운영자 화면](http://127.0.0.1:5173/admin)을 엽니다.
2. ‘로컬 운영자 체험하기’를 누릅니다. 이 로그인은 개발용이며 실제 본인 계정 인증이 아닙니다.
3. ‘상품 관리’에서 왼쪽 상품을 고릅니다. 제목, 브랜드, 추천 이유, 이미지·쿠팡 주소, 카테고리와 모음집을 수정할 수 있습니다.
4. 위·아래 버튼으로 상품 순서를 바꿉니다. ‘방문자 화면에 이 상품 표시’를 해제하면 숨길 수 있습니다.
5. ‘홈 화면 문구’에서 히어로 제목·설명과 한 끼 모음집 제목을 바꿉니다.
6. ‘초안 저장’을 누르고 ‘미리보기’에서 확인합니다.
7. ‘로컬 화면에 반영’을 누르면 이 컴퓨터의 홈 화면이 바뀝니다. 인터넷에 배포되는 버튼은 아닙니다.

저장한 초안은 새로고침해도 유지됩니다. 서로 다른 창에서 동시에 저장하면 이전 내용으로 덮어쓰지 않고 충돌을 알립니다. 저장 실패 시 편집 중인 내용은 화면에 남습니다. 새 상품을 실수로 추가했다면 저장 전 ‘새 상품 추가 취소’를 누릅니다.

## 공개 전에 필요한 사항
- 지금 주소는 쿠팡 파트너스 가입에 제출할 공개 홈페이지 주소가 아닙니다. 사용자가 최종 Vercel 배포와 공개 주소 생성을 직접 진행하기로 했습니다. 이번 작업에서는 외부 배포를 하지 않습니다.
- 사용자 결정에 따라 상품 사진 18개는 공란으로 둡니다. 상품 설명·출처·쿠팡 링크는 그대로 표시합니다. 사진을 표시하려면 승인된 파트너스 자료, 직접 촬영 사진 또는 사용 허락을 받은 이미지인지 확인해야 합니다.
- 사용권 확인 전 사진의 주소는 방문자 데이터에서 제외하며 이미지를 요청하지 않습니다. 상품 자체는 유지합니다. 관리자의 원본 이미지 주소는 보관하고, 사진 변경 시 사용권 상태는 다시 확인 전으로 돌아갑니다. ‘연결·공개 준비 → 공개 화면 미리보기’에서 공란 상태를 볼 수 있습니다.
- 공개 운영자 계정은 Sites 로그인 후 발급되는 본인의 계정 ID를 호스팅 환경변수 `ADMIN_USER_ID`에 등록해야 합니다. 빈 값이면 누구도 관리자 권한을 얻지 못합니다. 이메일·방문자 로그인만으로 관리자 권한이 생기지 않습니다.
- 파트너스 가입 후 본인 제휴 링크를 각 상품에 등록하고 ‘연결·공개 준비 → 쿠팡 파트너스 제휴 안내 표시’를 켭니다. 안내 설정만 켜서는 수익이 발생하지 않습니다.
- 상품 자동 갱신과 쿠팡 주간·월간 인기 순위는 아직 연결하지 않았습니다. 실제 API 권한과 제공 데이터를 확인한 뒤 진행합니다. 현재 추천을 쿠팡 공식 인기 순위로 표시하지 않습니다.
- 일부 상품은 이미지와 판매 옵션의 패키지·수량이 다를 수 있습니다. 실시간 재고·가격·배송도 미확인입니다. 가격대 필터나 임의 가격·평점은 넣지 않았습니다.
- 방문자 회원가입·분석 도구·클릭 집계는 연결하지 않았습니다. 현재 방문자 화면은 외부 상품 사진을 요청하지 않습니다. 사용권 확인 후 사진 표시를 켜면 해당 이미지 서버와 통신합니다.
- 유료 서비스 신청, 도메인 구매, 배포는 하지 않았습니다. 월 3만 원은 예산 상한이며 실제 요금 확정이나 지출 승인이 아닙니다.

## 저장·Git 상태
로컬 데이터는 프로젝트 `.wrangler/state`에 저장됩니다. 이 폴더를 지우면 저장한 초안과 반영 내용이 사라지므로 임의로 삭제하지 마세요. 현재 SQL은 이 프로젝트의 신규 로컬 저장소에만 적용했습니다.

사용자 요청으로 프로젝트 폴더에 Git 저장소를 만들고 main 브랜치에서 첫 로컬 커밋을 준비했습니다. 최종 커밋은 git log -1로 확인할 수 있습니다. 원격 저장소 연결·push·PR·merge·배포는 진행하지 않았습니다. 비밀키를 코드에 넣지 않았으며 `.env*`, `.dev.vars*`, 로컬 저장소와 의존성 폴더는 Git 제외 대상으로 설정했습니다.

## Vercel 배포 관련 남은 작업
사용자는 최종 Vercel 배포와 공개 주소 생성을 직접 진행합니다. 이 프로젝트는 현재 Vinext·Cloudflare Workers·D1·Sites 로그인 구조이며, Vercel 배포용 변환은 이번 작업에서 수행하지 않았습니다.
- 방문자 화면뿐 아니라 저장소 접근과 관리자 로그인도 Vercel 환경에 맞게 연결해야 합니다. `cloudflare:workers` 전용 연결과 로컬 데이터 파일을 그대로 Vercel에 올려 운영할 수 없습니다.
- 관리자 초안 저장을 유지하려면 Vercel에서 접근 가능한 영구 저장소와 운영자 인증을 정해야 합니다. Vercel의 임시 파일에 저장하는 방식은 사용하지 않습니다.
- 기존 Sites 인증 헤더를 Vercel에서 본인 인증 근거로 그대로 사용하면 안 됩니다. 관리자 권한은 새 인증 방식에 연결한 뒤 활성화해야 합니다.
- 사진 공란 처리와 상품 설명·출처·링크 유지 결정은 배포 플랫폼과 관계없이 유지합니다.
- 공개용 로컬 검사에서 비로그인 관리자 POST 이후 쿠팡 이동이 지연되는 문제를 발견해, 요청 본문을 최대 1MB까지 읽고 정리하도록 수정했습니다. 수정 후 차단 응답과 후속 이동이 정상이며, 한글 분할 입력과 초과 크기 차단 테스트를 통과했습니다.
